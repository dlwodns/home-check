## 구조 (11/13 결정)

- 프론트엔드 · 백엔드를 따로 나누지 않고 **Next.js 앱 하나** 안에서 층을 나눔
  - `data/` 내용(단계 · 체크리스트 · 용어 · 근거) / `lib/registry/` 등기부등본 읽기 · 판정(화면과 분리, 정답표로 테스트) / `lib/store/` 진행 저장(브라우저 → Supabase로 갈아 끼움) / `app/` 화면 / `tests/` 자동 테스트
- 등기부등본 점검은 **브라우저 안에서만** 처리 (서류가 서버로 전송되지 않음)
- GitHub에 올릴 때마다 자동 테스트(CI)
