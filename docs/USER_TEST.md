# 직접 써 보기 체크리스트 (A8)

20살 첫 계약자라고 생각하고, **설명을 안 읽어도 따라갈 수 있는지**를 봐 주세요. 막히거나 이상한 곳은 맨 아래 '발견한 것'에 한 줄씩 적으면 됩니다.

- 여는 법: 배포 주소 **https://home-check-pi.vercel.app** (PC · 휴대폰 모두). 내 컴퓨터에서 켰다면 `npm run dev`가 알려 주는 주소(기본 `http://localhost:3000`)
- PC에서 휴대폰 화면을 보려면 브라우저 창을 좁게 하거나, 크롬 F12 → 휴대폰 아이콘
- 시험용 PDF는 VS Code 왼쪽 파일 목록에서 `samples/blind/pdf`, `samples/blind2/pdf`의 파일을 **오른쪽 클릭 → 다운로드**해서 내 PC로 받은 뒤 올리면 됩니다. 각 서류가 무엇을 시험하는지는 같은 폴더의 `CASES.md`에 있어요.

## 1. 처음 들어와서 (로그인 없이)

- [ ] 홈 화면만 보고 "무엇을 하는 앱인지" 바로 알겠다
- [ ] '후보 방 추가'로 방 하나를 담았다 (주소 예: `마포구 서교동 123-4`, 보증금 10,000,000원, 월세 600,000원)
- [ ] 같은 이름 동이 여러 곳인 주소(예: `신사동 12`)를 넣으면 고르는 버튼이 나온다
- [ ] 방 화면에 **동네 시세**(비슷해요 / 높은 편 / 낮은 편, 범위)가 나온다
- [ ] 방 화면에서 '중개사 / 직거래'를 골랐다

## 2. 등기부등본 점검

- [ ] 방 화면 → '등기부등본 올려서 점검하기' → **주의 샘플** → 점검하기 → 결과로 바로 이동한다
- [ ] 신호등 · 큰 제목 · 확인할 것 · 괜찮은 점(초록)이 한눈에 들어온다
- [ ] 결과의 **초록 점선 단어**를 누르면 말풍선이 뜨고, 바깥을 누르면 닫힌다 (PC는 마우스를 올려도 뜸)
- [ ] '이 방으로 돌아가 계약 방법 보기' → 방 카드에 신호등이 남아 있다
- [ ] '앞선 세입자 보증금, 어떻게 확인해요?'를 열어 보면 무엇을 들고 어디 가는지 알겠다
- [ ] 다음 행동의 '복사' · '요약 복사'가 된다

## 3. 시험용 PDF 올려 보기 (정확도 직접 확인)

결과가 `CASES.md`의 설명과 맞는지 봐 주세요.

- [ ] `samples/blind/pdf/B04.pdf` — 공동 소유. 집주인이 두 명으로 나오고, 한 명만 계약하러 오면 '위험'
- [ ] `samples/blind/pdf/B08.pdf` — 먼저 설정된 **전세권**을 알려 준다
- [ ] `samples/blind2/pdf/C05.pdf` — **가처분**이 남아 있다고 알려 준다
- [ ] `samples/blind2/pdf/C06.pdf` — 근저당 3억 1,200만 원을 놓치지 않는다
- [ ] (자유) 다른 파일 몇 개도 올려 보고, 설명과 다른 결과가 있으면 적기

## 4. 단계 · 계약 과정

- [ ] 방 화면 '계약 과정'이 3단계(집 보러 가기)부터 시작한다 (방을 찾았으니 1 · 2단계는 건너뜀)
- [ ] 4단계에서 체크하면 그 방에만 저장된다 (다른 방에는 체크가 안 생김)
- [ ] 첫 안내의 '다 알아요 · 끄기'로 밑줄이 꺼지고, 진행 화면에서 다시 켤 수 있다

## 5. 로그인 (선택 기능)

- [ ] 홈 오른쪽 위 '로그인' → '처음이에요 · 가입' → 비밀번호 두 번 → '이 주소가 맞나요?' 확인 → 가입
- [ ] '내 계정'에 "계정에도 저장돼 있어요"가 나온다
- [ ] **다른 브라우저(또는 시크릿 창)**에서 로그인하면 아까 담은 방이 보인다
- [ ] 틀린 비밀번호를 넣으면 쉬운 말로 알려 준다
- [ ] 다 해 봤으면 '내 계정 → 계정 삭제'로 시험 계정을 지운다

## 5-1. 남의 방이 안 보이는지 (계정 2개)

- [ ] 계정 A로 방을 하나 담고, 다른 브라우저에서 계정 B로 로그인했을 때 A의 방이 **보이지 않는다**
- [ ] 다 해 봤으면 두 계정 모두 '계정 삭제'
