# 홈체크 화면 흐름 (v0.1)

- 작성일: 2026-11-06
- 화면 스케치(휴대폰 크기 10장, 눌러 볼 수 있음): https://claude.ai/artifact/K2MHJhnSbeNk3YX7KBr6wD
  - 비공개 링크입니다. 다른 사람에게 보여 주려면 페이지의 공유 메뉴에서 공유해야 합니다.
- 기준 인물: 타지역 대학에 입학하는 20살, 첫 집계약. 모든 화면은 "이 사람이 설명 없이 따라 할 수 있나?"로 판단합니다.

## 흐름

```
시작 ─┬─ 처음이에요 ─→ 어디서 찾았어요? ─→ 내 계약 진행(6단계)
      └─ 해 봤어요 ───────────────────────→ 내 계약 진행(6단계)

내 계약 진행 ─→ 단계 체크리스트 ─→ 등기부등본 점검 입력 ─→ 점검 결과 ─→ 다음 행동 카드
                    │
                    └─ 막히면 물어보세요 ─→ 홈체크 도우미

어디서든 "저장하기" ─→ 로그인(카카오 · Google · 나중에)
하단 메뉴: 진행 / 내 후보 방 / 내 정보
```

## 화면 목록

| # | 화면 | 핵심 | PRD |
| --- | --- | --- | --- |
| 1 | 시작 | 처음이에요 / 해 봤어요. 로그인 없이 둘러보기 | F1, F0 |
| 2 | 어디서 찾았어요? | 공인중개사 / 직거래 / 아직 못 찾았어요. 직거래면 본인 확인 안내 | F1 |
| 3 | 내 계약 진행 | 6단계 진행률, "지금 할 차례" 강조, 후보 방 표시 | F1 |
| 4 | 단계 체크리스트 | 항목별 "왜 중요해요?" · 근거 보기 · 용어 밑줄 설명 · HUG 앱 연결 · 도우미 버튼 | F1, F5 |
| 5 | 로그인 | 카카오 · Google · 나중에. 저장하는 것 / 저장하지 않는 것 안내 | F0 |
| 6 | 등기부등본 점검 입력 | PDF 또는 글자 붙여 넣기, 보증금 · 월세 · 시세(모르면 비움) · 계약 상대 이름, 샘플로 해 보기 | F2 |
| 7 | 점검 결과 | 주의 / 위험 / 괜찮음 카드, 70% · 80% 참고선 표시, AI가 읽은 내용 확인 · 고치기 | F2 |
| 8 | 다음 행동 카드 | 질문 문장, 특약 문장(S5), 부모님께 보내기(카카오톡 · 이미지) | F3 |
| 9 | 내 후보 방 | 방별 진행률 · 점검 결과 비교, 방 추가(링크 붙여 넣기) | F4 |
| 10 | 홈체크 도우미 | 근거 안에서만 답함, 질문 문장 작성, 체크리스트 표시 | F5 |

## 디자인 원칙

- 색: 기본 초록(신뢰), 주의 주황, 위험 빨강. 색만으로 구분하지 않고 글자 · 아이콘을 함께 씀
- 버튼 높이 44px 이상(손가락으로 누르기 쉽게)
- 어려운 용어는 점선 밑줄 → 한 줄 설명
- 결과 화면마다 "참고용 안내, 최종 확인은 전문가에게" 문구
