## 1. 한 줄 소개

방을 찾은 **다음부터** 계약을 무사히 마칠 때까지, 지금 할 일을 단계별로 알려 주는 웹 앱입니다. 등기부등본을 올리면 AI가 쉬운 말로 위험 신호를 설명하고, **다음에 무엇을 해야 하는지**까지 알려 줍니다.

**형태**: 모바일 우선 웹 + PWA (설치 없이 링크로 바로 열고, 원하면 홈 화면에 아이콘 추가). 앱스토어 앱은 만들지 않음. 휴대폰 화면 기준으로 설계하고 PC에서도 깨지지 않게 함. 발표 시연은 휴대폰 화면으로.

## 2. 문제

### 이 사람을 돕습니다 (주 타깃)

> **20살 대학 예비 입학생.** 타지역 대학에 붙어서 처음으로 혼자 집을 계약해야 한다. 학교 근처 월세 원룸을 찾는 중이다. 보증금은 부모님이 보태 주신다. 집을 자주 보러 갈 수 없고, 근저당 · 확정일자 · 전입신고 같은 말은 처음 듣는다. **"뭐부터 해야 할지 아무것도 모르겠다."**

### 이 사람이 겪는 어려움

| 어려움 | 결과 |
| --- | --- |
| 무엇을 어떤 순서로 해야 하는지 모름 | 성수기(12~2월)에 급하게 계약하다 확인 단계를 건너뜀 |
| 등기부등본 · 건축물대장을 읽을 줄 모름 | 집주인 확인, 빚(근저당) 확인을 하지 못함 |
| "중개사가 있으니 괜찮겠지"라고 생각함 | 직접 확인해야 할 것을 중개사에게 맡겨 버림 |
| 직거래로 중개수수료를 아끼려 함 | 집주인 본인 확인 같은 보호 절차가 빠짐 |
| 위험하다는 말을 들어도 무엇을 해야 할지 모름 | 그냥 계약하거나, 막연히 불안해함 |

### 근거 (실제 사례)

- 익산: 원룸 임대업자가 대학생 등 임차인 122명의 보증금 약 47억 원을 가로챔 (뉴시스, 2019)
- 전주: 방 13개 다세대주택을 36개로 불법으로 쪼개 대학생 세입자에게 세를 놓음 (전북일보, 2023)
- 인터넷 카페 직거래로 20대 대학생 · 사회초년생 7명이 사기 피해. 경찰은 등기부등본으로 실제 소유주와 계약자가 같은지 확인하라고 당부함 (매일신문, 2024)

## 4. 기존 서비스와 차별점

| 서비스 | 하는 일 | 빈 곳 |
| --- | --- | --- |
| 직방 · 다방 · 피터팬 · 네이버 부동산 | 방 찾기 (직방은 AI 진단 기능도 있음) | 방을 고른 **뒤 무엇을 할지**는 안내하지 않음 |
| HUG 안심전세 앱 (공공) | 주소로 위험 진단, 집주인 체납 · 사고 이력, 시세 | **전세** 중심이고 기능이 많아 초보자가 어디부터 볼지 모름 |
| 서울시 · 경기도 AI 진단, 홈큐, 세이프홈즈 | 전세 위험 분석 | **확인할 줄 아는 사람**을 위한 판정 도구 |

*2026년 기능은 언론 보도 기준 (S10)*

**홈체크의 차별점**

1. **방 찾기 다음부터 이어지는 계약 단계 길잡이**: 지금 몇 단계인지, 다음에 무엇을 할지
2. **대학가 월세 원룸 · 직거래에 특화**: 다가구 원룸의 앞선 세입자 보증금, 불법 개조, 직거래 본인 확인
3. **판정에서 끝나지 않고 다음 행동까지**: 중개사에게 물어볼 질문, 특약 문장 예시, 부모님께 보낼 요약

기존 서비스와 경쟁하지 않고 **연결**합니다. (예: "이 단계에서는 HUG 안심전세 앱으로 집주인 체납 이력을 확인하세요")

**방 검색은 직접 만들지 않습니다.** 공개된 매물 API가 없고, 방 찾기 앱의 데이터를 긁어 오는 것은 이용약관 · 법적 문제가 있으며, 큰 앱들과 정면으로 겹쳐 홈체크의 위치가 흐려지기 때문입니다. 대신 **찾은 방을 담아 두는 "내 후보 방"**(F4)으로 연결합니다.

## 5. 기능

핵심 기능 3개(F1~F3) + 기반 기능(F0 로그인) + 3주차 기능(F5 도우미 에이전트 → F4 내 후보 방 순서)

### F1. 계약 단계 길잡이

- 시작 화면: **처음이에요 / 해 봤어요**
- 첫 질문: **"이 방, 어디서 찾았어요?"** → 공인중개사를 통해서 / 집주인과 직접(직거래)
- 6단계 체크리스트. 항목마다 "왜 중요해요?" 한 줄 설명과 **"근거 보기" 링크**(SOURCES 번호 → 공식 확인 링크)를 붙임
- **용어 한 줄 설명**: 근저당 · 확정일자 · 전입신고 · 특약 같은 용어에 점선 밑줄 → 누르면 한 줄 설명. 설명은 **용어 사전 파일 하나**에 모아 모든 화면과 AI 설명이 같이 씀 (예: 근저당 = "집주인이 이 집을 담보로 잡히고 빌린 돈이에요. 집이 경매로 넘어가면 이 돈부터 갚아요.")

| 단계 | 내용 |
| --- | --- |
| 1. 준비 | 예산, 부모님과 상의, 기숙사 결과 확인 |
| 2. 집 찾기 | 학교 근처 시세, 방 찾기 앱, 중개사무소 찾기 |
| 3. 집 보러 가기 | 현장 체크리스트 (수압, 곰팡이, 보안, 소음 등) |
| 4. 계약 전 서류 확인 ★ | 등기부등본 · 건축물대장 확인 → **F2로 연결**. 다가구 원룸은 앞선 세입자 보증금 확인 (S5, S6, S7) |
| 5. 계약하는 날 | 계약서 확인, 특약, 보증금 입금 계좌 확인 |
| 6. 입주 후 | 전입신고(14일 이내), 확정일자 (S9) |

**분기별 체크리스트**

- **공인중개사를 통해서**
  1. 등록된 중개사무소인지 조회 (S3)
  2. 상대가 공인중개사인지, 중개보조원인지 확인 (S1, S2, S3)
  3. 중개대상물 확인 · 설명서 받기
  4. 공제증서 사본 받기
  5. 등기부등본을 계약 당일 직접 다시 발급 → F2
  6. 중개수수료 상한 확인 (S4, 지역 조례 확인)
- **집주인과 직접(직거래)**
  1. 계약하러 온 사람이 등기부등본의 소유자와 같은지 신분증으로 확인 (S11)
  2. 보증금 입금 계좌가 소유자 본인 명의인지 확인 (S11)
  3. 대리인이면 위임장 · 인감증명서 확인 (S11)
  4. 등기부등본 · 건축물대장 직접 발급 → F2
  5. 표준 임대차계약서 사용

### F2. 등기부등본 AI 점검

1. 사용자가 등기부등본을 올림 (MVP: 텍스트 붙여 넣기 또는 텍스트 PDF)
2. **AI는 읽기만**: 소유자, 근저당 금액, 압류 · 가압류 여부, 최근 소유권 이전 등 항목을 뽑아 정해진 형식으로 정리
3. **판정은 규칙으로**: 예) 소유자 ≠ 계약 상대, 압류 · 가압류 있음, (채권최고액 + 앞선 보증금 + 내 보증금) ÷ 시세가 70% 초과 주의 · 80% 이상 위험 → ⚠️
   - 70% · 80%는 **법정 기준이 아니라 많이 쓰는 참고선**(S8). 화면에 그대로 밝히고, 공식 진단은 HUG 안심전세 앱으로 연결
4. **AI는 설명만**: 판정 결과를 20살이 이해할 쉬운 말로 풀어 줌

### F3. 다음 행동 카드

판정 결과마다 다음 행동을 보여 줍니다.

- **이렇게 물어보세요**: 중개사 · 집주인에게 보낼 질문 문장
- **계약서에 이렇게 적어요**: 특약 문장 예시
- **부모님께 보내기**: 결과 한 장 요약 (복사 또는 이미지로 저장)

### F0. 로그인 · 진행 저장 (기반 기능)

- **로그인 없이 둘러보기** → 진행 상황을 저장하려면 로그인. 처음 온 20살이 가입 벽에 막히지 않게 함
- 로그인 방식: **카카오 로그인**(20살에게 가장 익숙) + Google. Supabase Auth 사용
- 저장하는 것: 단계별 체크 상태, 내 후보 방, 점검 결과 **요약**(안전 · 주의 · 위험과 이유)
- **저장하지 않는 것**: 등기부등본 원문, 집주인 이름 등 다른 사람의 개인정보
- 휴대폰과 PC 어디서 열어도 이어서 진행 가능

### F5. 홈체크 도우미 (에이전트, 3주차 우선)

- 화면 아래 **"막히면 물어보세요"** 버튼 → 대화창
- 뼈대는 F1 단계 길잡이 그대로 두고, 막힐 때 묻는 **보조** 역할 (채팅만으로 진행하지 않음)
- 도우미가 쓸 수 있는 도구는 **3개로 제한**
  1. 용어 사전 · 근거 목록(SOURCES) **안에서만** 질문에 답하기 (목록에 없으면 "확실하지 않아요 + 확인 방법" 안내)
  2. 지금 단계의 체크 항목 표시하기
  3. 집주인 · 중개사에게 보낼 질문 문장 만들기
- 위험 판정은 하지 않음 (F2 규칙의 결과만 설명)
- 플랜 B: 도구 사용이 불안정하면 1번(근거 안에서 답하기)만 남김

### F4. 내 후보 방 (여유 시, 3주차 F5 다음)

- 직방 · 다방 · 피터팬에서 찾은 방의 **링크 · 주소 · 보증금 · 월세 · 찾은 경로(중개사/직거래)**를 저장
- 방마다 체크리스트 진행 상황과 점검 결과가 따로 붙음
- 후보 방 2~3개를 한 화면에서 비교 ("이 방은 확인 4개 남았어요")

## 6. 하지 않을 것

- 방 매물 검색 · 추천 (직방 · 다방의 영역. 대신 F4 내 후보 방)
- 실시간 시세 조회, 공공 API 연동 (3주 범위 밖. 시세는 사용자가 입력)
- 법률 판단 · 계약 대행 ("최종 확인은 전문가에게" 안내)
- 등기부등본 원문 · 다른 사람 개인정보 저장 (데모는 **가짜 샘플 등기부등본**만 사용)

## 7. AI 설계 원칙

| 역할 | 누가 |
| --- | --- |
| 서류에서 항목 읽어 내기 | AI |
| 위험 판정 | **정해진 규칙** (AI가 판정하지 않음) |
| 쉬운 말 설명, 질문 · 특약 문장 다듬기 | AI |
| 도우미 대화 (F5) | AI 에이전트. 단, 용어 사전 · 근거 목록 안에서만 답하고 도구는 3개로 제한 |

- AI가 서류에 없는 내용을 지어내지 않도록 지시하고, 읽어 낸 값은 사용자가 화면에서 확인 · 수정할 수 있게 함
- 모든 결과 화면에 "참고용 안내이며, 최종 확인은 공인중개사 · 법률 전문가에게" 문구
- AI: OpenRouter (my-intro와 같은 방식)

**필요한 키** (값은 `.env`에만, 환경 변수로만 읽음)

| 이름 | 용도 |
| --- | --- |
| `OPENROUTER_API_KEY` | AI 호출 (서버 전용) |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 프로젝트 주소 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase 공개 키 (브라우저용, 권한은 DB 보안 규칙으로 제한) |

카카오 · Google 로그인 키는 Supabase 대시보드에만 등록하고 코드에는 넣지 않음

## 8. 데모 시나리오 (초안, 3분)

1. "타지역 대학에 붙은 20살, 처음 집을 구해요" → **처음이에요**
2. "어디서 찾았어요?" → **직거래** → 직거래 전용 체크리스트가 나타남
3. 4단계에서 **가짜 샘플 등기부등본**을 붙여 넣음
4. ⚠️ "계약하러 온 사람과 집주인 이름이 달라요", "근저당이 커요"
5. 다음 행동 카드: 집주인에게 보낼 질문, 특약 문장, **부모님께 보내기** 요약
6. (3주차 완성 시) 막힌 용어를 도우미에게 물어봄 → 근거 번호와 함께 답함
7. 마무리: "방은 직방에서 찾고, 계약은 홈체크와 함께"

## 9. 성공 기준

- 처음 쓰는 사람이 설명 없이 6단계를 끝까지 따라갈 수 있다
- 샘플 등기부등본 3종(안전 · 주의 · 위험)에서 판정이 의도대로 나온다
- 위험 판정마다 다음 행동 카드가 1개 이상 나온다
- 배포 링크로 접속해서 휴대폰에서 쓸 수 있다
