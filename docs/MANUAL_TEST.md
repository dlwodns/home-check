# 직접 점검표 (11/23, 공유 지분 규칙 반영) — 23개 서류 한 번씩

주소: https://home-check-pi.vercel.app · 서류는 모두 **지어낸 가짜**예요. 결과가 '기대 판정'과 다르면 한 줄로 적어 주세요.

## 1. 한 장씩 하는 법 (서류 1개에 약 1분)

1. 홈 → **등기부등본만 바로 점검하기** (방을 만들지 않아도 돼요)
2. **등기부등본 PDF 올리기** → 아래 표의 파일(VS Code에서 우클릭 → Download로 받은 것)
3. **2. 내 계약 정보** 4칸에 표의 값을 그대로 (단위 만 원, '비움'은 비워 두기)
4. **점검하기** → 신호등과 '확인할 것' 제목이 표와 같은지 보고 ☐에 체크
5. 다음 서류: 위쪽 **고쳐서 다시 점검** → 새 PDF 올리기 → 4칸 바꾸기

> 같은 결과가 PDF와 글자 붙여 넣기에서 모두 나오는지도 보고 싶으면, 같은 폴더의 `.txt` 파일 내용을 복사해 붙여 넣어 보세요.

샘플 버튼과 같은 서류라, 4칸은 샘플 버튼을 눌렀을 때 채워지는 값을 쓰면 돼요.

## 4. 흐름 · 저장 · 이상한 입력 (한 번씩)

- ☐ 방 담기 → 그 방에서 PDF 점검 → 방 카드에 신호등 · 진행 막대(4단계 '등기부등본 점검하기' 체크됨)
- ☐ 새로고침해도 방 · 체크가 그대로
- ☐ 같은 방에서 샘플 버튼으로 점검하면 '샘플이라 저장하지 않았어요'가 나오고 방 결과는 안 바뀜
- ☐ 가입 → 다른 기기(휴대폰)에서 로그인 → 같은 방이 보임
- ☐ 방 지우기 → 홈에서 사라짐
- ☐ 보증금 칸에 글자 · 아주 큰 숫자 → 알아듣기 쉬운 안내, 앱이 멈추지 않음
- ☐ 등기부가 아닌 PDF(아무 문서) · 사진 PDF → '등기부등본이 아닌 것 같아요' 류 안내, 신호등이 나오지 않음
- ☐ 점검하기 버튼 빠르게 두 번 → 결과 · 방이 두 개로 늘지 않음
- ☐ 휴대폰에서 처음부터 끝까지 한 번 (글자 크기 · 버튼 누르기 편한지)
