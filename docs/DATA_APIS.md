# 홈체크 외부 데이터 API 메모

키 값은 `.env`에만 둔다. 이 문서에는 키 이름만 적는다.

## 1. 국토교통부 단독/다가구 전월세 실거래가 자료 (F6 동네 원룸 시세)

- 출처: 공공데이터포털 15126472, 국토교통부 오픈API 활용 가이드(사용자가 받은 한글 파일, 2026-11-13 확인)
- 키: `DATA_GO_KR_API_KEY` (서버에서만 읽음). 2026-11-13 실제 호출 성공 (마포구 2026년 10월 364건)
- 운영: 한국부동산원, 데이터 갱신 하루 1회, 초당 최대 30건, 평균 응답 500ms

### 요청

`GET https://apis.data.go.kr/1613000/RTMSDataSvcSHRent/getRTMSDataSvcSHRent`

| 값 | 필수 | 설명 |
| --- | --- | --- |
| `serviceKey` | 필수 | 인증키 (URL 인코딩해서 보냄) |
| `LAWD_CD` | 필수 | 법정동 코드 10자리 중 **앞 5자리(시군구)**. 예: 서울 종로구 11110, 마포구 11440 |
| `DEAL_YMD` | 필수 | 계약 연월 6자리. 예: 202610 |
| `pageNo` · `numOfRows` | 선택 | 페이지 번호 · 한 페이지 건수 |

### 응답 (**XML만 제공**, JSON 없음)

| 항목 | 뜻 | 주의 |
| --- | --- | --- |
| `umdNm` | 법정동 (예: 현석동) | 동 단위까지만. 번지는 없음 |
| `houseType` | 단독 / 다가구 | |
| `deposit` | 보증금 (만 원) | **"10,000"처럼 쉼표가 들어간 글자** → 숫자로 바꿀 때 쉼표 제거 |
| `monthlyRent` | 월세 (만 원) | 0이면 전세 |
| `totalFloorAr` | **연면적** | 방 하나 면적이 아니라 건물 연면적일 수 있음 → 방 크기 비교에 쓰지 않음 |
| `dealYear` · `dealMonth` · `dealDay` | 계약일 | |
| `buildYear` | 건축년도 | 비어 있을 수 있음 |
| `contractType` · `contractTerm` · `useRRRight` · `preDeposit` · `preMonthlyRent` | 신규/갱신, 계약기간, 갱신요구권, 종전 보증금 · 월세 | 비어 있거나 공백 한 칸일 수 있음 |

### F6 구현 (11/17 완료)

- 주소 → 시군구 코드: `data/regions.json` = 행정표준코드관리시스템(code.go.kr) '법정동코드 전체자료' 2026-11-16 내려받음, 폐지여부 '존재'인 읍 · 면 · 동 5,067개(시군구 256개). 다시 만들 때도 같은 파일에서 뽑기
- **행정구역 통합 주의**: 표에 '전남광주통합특별시'(12xxx)가 있음. 실거래 API도 새 코드로 옛날 달까지 옮겨져 있음(11/17 확인: 여수 12130은 2026-05 · 06 · 07 · 10 모두 거래 있음, 옛 코드 46130은 0건). 표를 바꿀 때 실거래 API 코드와 맞는지 다시 확인
- 법정동코드 API(행정안전부 StanReginCd)와 건축물대장 API는 이 키로 '등록되지 않은 서비스키' → 활용 신청 전에는 못 씀(파일 방식으로 대체)
- 서버 처리: `lib/rentServer.ts`(키 · 캐시 · 재시도), 계산: `lib/rent.ts`, 화면: `app/room/RentCard.tsx`
- 배포(Netlify)에는 환경 변수 `DATA_GO_KR_API_KEY`를 넣어야 함. 오류 32(등록 안 된 IP · 도메인)가 나오면 활용 신청 정보에 배포 주소 추가

### F6 만들 때 할 일 (계획 당시 메모)

1. 주소 → 시군구 코드(5자리): 행정표준코드관리시스템(code.go.kr) 법정동 코드표를 `data/`에 넣어 브라우저 · 서버에서 찾기 (외부 호출 없이)
2. 최근 몇 달(예: 3개월)을 불러와 같은 동(`umdNm`)의 보증금 · 월세 분포(중앙값, 범위)를 보여 줌. 거래 수가 적으면 "참고용, 거래 N건"을 함께 표시
3. 같은 동네 · 같은 달 결과는 서버에 저장해 다시 씀 (하루 호출 한도와 응답 속도 때문)
4. 위 오류 코드별 문구를 테스트로 확인
