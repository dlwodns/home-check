# 샘플 등기부등본 (테스트용 가짜 서류)

**모든 이름 · 주소 · 번호 · 금융회사는 지어낸 값입니다.** 실제 서류나 개인정보는 이 폴더에 넣지 않습니다.

| 파일 | 상황 | 판정 | 무엇을 시험하나 |
| --- | --- | --- | --- |
| `A_safe.txt` | 예전 근저당이 **말소**됨, 계약 상대 = 집주인 | 안전 (13.1%) | 말소된 근저당을 빼고 계산하는지 |
| `B_caution.txt` | 근저당 2건, 합계가 시세의 76% | 주의 | 근저당 여러 건 합산, 70~80% 구간 (데모 주인공) |
| `C_danger.txt` | 최근 집주인이 바뀌었는데 **이전 소유자**가 계약하러 옴, 가압류, 101% | 위험 | 소유자 불일치, 갑구의 가압류, 최근 소유권 이전, 80% 이상 |

- 정답표: [`expected.json`](expected.json) — 규칙 기반 읽기가 뽑아야 할 값(`read`), 사용자가 입력하는 값(`inputs`), 판정 결과(`expected`, 이유는 `data/judge.json`의 코드)
- 최근 소유권 이전(참고)은 `rules.as_of`(2026-11-13) 기준으로 계산합니다.
- 시세 · 앞선 세입자 보증금 · 내 보증금은 등기부등본에 없으므로 `inputs`로 따로 줍니다.
- 판정 기준(70% · 80%)은 법정 기준이 아닌 참고선입니다. ([SOURCES S8](../docs/SOURCES.md))

## 한계

실제 등기부등본 PDF는 표 모양이 더 복잡합니다(줄 바뀜, 말소 사항은 빨간 줄 등). 이 샘플은 구조를 단순화한 글자 버전이며, 실제 PDF 모양 대응은 2주차 PDF 읽기 작업에서 따로 확인합니다.
